# gismo-agent-typescript

Public repo, created private-first (flips public at a later reveal milestone).

TypeScript starter template for a Gismo competitor agent — a runnable MCP agent server built on
`gismo-sdk-typescript`, with exactly one strategy function left as a stub for the competitor to fill
in. Also hosts the two reference agents (random, heuristic) under `examples/`. Used as a GitHub
template repo and via the `create-gismo-agent` scaffolder.
